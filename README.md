# 🎯 Quiz Challenge

A simple and interactive Quiz App with a beautiful UI.

**"5 questions. How many can you get right?"**

### 🔗 Live Demo
👉 https://laibasarwar87.github.io/Quiz-Challenge/

### ✨ Features
- 5 Interactive MCQs
- Instant Result & Score
- Clean and Responsive Design
- Neon Glow UI
- Works on Mobile and Desktop

### 🛠️ Tech Stack
- HTML5
- CSS3
- JavaScript (Vanilla)

### 🚀 How to Run Locally
1. Clone the repo:
   `git clone https://github.com/sarwar87/Quiz-Challenge.git`
2. Open `index.html` in your browser
3. Click on "Start Quiz" and enjoy!
